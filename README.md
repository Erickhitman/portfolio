## 🚀 Portfólio Pessoal - Erick

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto é a minha vitrine como desenvolvedor — um espaço onde apresento minha trajetória, os projetos que construí, minha stack e como eu penso sobre tecnologia.

> "Não quero apenas escrever código. Quero entender problemas e construir soluções."

## 📌 Sobre o Projeto

Um site one-page com estética **editorial dark + roxa**, inspirado na composição visual de portfólios fotográficos mas traduzido para o universo do desenvolvimento de software. A direção visual foi pensada para transmitir técnica, criatividade e atenção ao detalhe — sem parecer um template genérico.

Ele reúne minha formação e experiência em:

- **Análise e Desenvolvimento de Sistemas** — Fatec
- **Web Design / Desenvolvimento Web** — SENAI
- **Back-end (Java + Spring Boot)** — SENAI
- **ServiceNow** — SENAI (em andamento)

## 🧭 Estrutura do Site

| Seção           | O que mostra                                               |
| --------------- | ---------------------------------------------------------- |
| **Hero**        | Apresentação com terminal animado e chips de stack         |
| **Sobre**       | Formação, interesses e objetivos                           |
| **Projetos**    | EhFraude?, Mihon Extension, Urban Barber + repos do GitHub |
| **Habilidades** | Stack organizada por categoria                             |
| **Trajetória**  | Timeline de evolução (sem datas forjadas)                  |
| **Contato**     | GitHub, LinkedIn e e-mail                                  |

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica.
- **CSS3** — Grid, Flexbox, animações, variáveis e efeitos de glow/glass.
- **JavaScript (vanilla)** — Scrollspy, reveal, parallax sutil, menu mobile.
- **Google Fonts** — Inter (texto), Montserrat (display), JetBrains Mono (código).
- **SVG inline** — Ícones sem dependências externas.
- **Design Responsivo** — Mobile-first adaptado para todas as telas.

## 🚀 Personal Portfolio - Erick

Welcome to my personal portfolio repository! This project is my showcase as a developer — a space where I present my journey, the projects I've built, my stack, and how I think about technology.

> "I don't just want to write code. I want to understand problems and build solutions."

## 📌 About the Project

A one-page site with an **editorial dark + purple** aesthetic, inspired by the visual composition of photography portfolios but translated into the world of software development. The visual direction was designed to convey technical skill, creativity, and attention to detail — without looking like a generic template.

It brings together my background and experience in:

- **Systems Analysis and Development** — Fatec
- **Web Design / Web Development** — SENAI
- **Back-end (Java + Spring Boot)** — SENAI
- **ServiceNow** — SENAI (in progress)

## 🧭 Site Structure

| Section          | What it shows                                              |
| ----------------- | ----------------------------------------------------------- |
| **Hero**          | Introduction with animated terminal and stack chips          |
| **About**         | Background, interests, and goals                            |
| **Projects**      | EhFraude?, Mihon Extension, Urban Barber + GitHub repos     |
| **Skills**        | Stack organized by category                                 |
| **Journey**       | Evolution timeline (no fabricated dates)                    |
| **Contact**       | GitHub, LinkedIn, and email                                  |

## 🛠️ Technologies Used

- **HTML5** — Semantic structuring.
- **CSS3** — Grid, Flexbox, animations, variables, and glow/glass effects.
- **JavaScript (vanilla)** — Scrollspy, reveal, subtle parallax, mobile menu.
- **Google Fonts** — Inter (text), Montserrat (display), JetBrains Mono (code).
- **Inline SVG** — Icons with no external dependencies.
- **Responsive Design** — Mobile-first, adapted for all screens.

## 🎨 Features

- [x] Fixed navigation menu with blur on scroll.
- [x] Scrollspy highlighting the active section in the menu.
- [x] Hero with a terminal that "types out" lines of code.
- [x] Project mockups built purely in CSS (no generic images needed).
- [x] Real screenshots of the **EhFraude?** prototype in editorial frames.
- [x] Subtle entrance animations (reveal via IntersectionObserver).
- [x] Support for `prefers-reduced-motion`.
- [x] Consistent dark theme with a purple identity.
